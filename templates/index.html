Comment interpréter les résultats ?

  • Bon client (défaut = 0) : probabilité de défaut faible le prêt peut être accordé.
  • Mauvais client (défaut = 1) : probabilité de défaut élevée le prêt doit être refusé ou renégocié.
  • Niveau de risque :
    • Faible : probabilité < 30 %
    • Moyen : 30 % ≤ probabilité < 60 %
    • Élevé : probabilité ≥ 60 %

Utilisation de l'API

L'API REST est également disponible :

  • GET /health État de l'API
  • GET /model/info Informations du modèle
  • POST /predict Prédiction unitaire (JSON)
  • POST /predict/batch Prédiction multiple (JSON)
  • POST /predict/csv Prédiction depuis un CSV
  • GET /docs Documentation Swagger interactive
